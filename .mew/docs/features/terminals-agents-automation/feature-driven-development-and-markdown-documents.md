The feature panel and its dedicated API, CLI, and execution queue were removed on 2026-10-26. See the [removal decision](../../decisions/0065-remove-feature-panel.md) and [previous contracts and verification records](../../history/feature-development.md).

Feature specification Markdown can still be read and edited in Documents. Existing branch metadata, execution history, and browser drafts are not automatically deleted or migrated, and the app does not read or execute them. Git operations and `/포트번호` previews remain available through their existing entry points.
