## 요구사항

- 프로젝트 작업용 셸을 열고 연결을 이어 간다.

### 범위

- 터미널 기본 배경은 투명해 패널 바탕이 비친다. 글씨·커서·ANSI 팔레트와 선택 모드 화면은 mew의 라이트·다크 테마를 따른다.

- 일반 셸 탭 생성·재연결·입력·세션 종료와 터미널 명령 버튼을 제공한다.
- 프로젝트 명령이 연 localhost TCP 수신 포트를 감지해 같은 명령 줄에서 앱을 연다.
- 입력 영역의 배경·입력칸·전송 버튼 디자인을 에이전트 패널과 통일한다.

### 경계와 제한

- 일반 셸과 공식 에이전트 TUI는 서로 다른 패널에 속한다.
- 패널을 닫는 것과 세션을 종료하는 것은 다르며 서버 OS 권한으로 실행한다.

## 구현 내용

- Linux·macOS는 기존 tmux, Windows 네이티브는 psmux·PowerShell을 사용한다. backend가 생성·명령·attach·입력·capture·clipboard 제어의 실행 파일과 argv를 소유하며 기존 tmux API·세션 ID는 유지한다. Windows 상태 경로별 namespace로 사용자 세션과 분리한다. 구현과 Windows CI·공개 지원 게이트는 [OS 실행 계약](../../development/windows-native.md)을 따른다.

- 명령 메뉴는 이름이 더 보이도록 폭을 넓히고 글자·여백·조작 너비를 줄인다. 포트 번호는 테마 배경과 테두리가 있는 작은 컨테이너로 구분하며 화면 너비의 90% 이내에서 배치한다. 구체적인 크기는 [공용 UI 계약](../../development/ui-contracts.md#드롭다운과-선택-컴포넌트)을 따른다.

- 프로젝트 명령 메뉴는 실행 세션의 `ports`를 정지·터미널 아이콘 왼쪽의 번호 버튼으로 표시한다. 포트가 여러 개면 오름차순으로 나열하고 해당 영역만 가로로 스크롤한다. 공통 툴팁과 네 언어의 접근성 이름을 제공하며 기존 좌우 방향키로 포트 버튼에도 접근한다. 클릭은 새 탭만 열고 실행·중지·터미널 팝업을 호출하지 않는다.
- `GET/PUT /api/cmd-buttons`는 실행 중인 버튼에 한해 pane PID와 자손 프로세스의 실제 수신 포트를 연결한다. 포트 미리보기 권한이 없거나 감지에 실패하면 `ports: []`를 반환하고 명령 목록과 실행 상태는 유지한다. 메뉴가 열린 동안의 3초 폴링에서 포트 개방·종료를 반영한다. 구버전 서버가 `ports`를 생략해도 기존 명령 조작은 유지한다. OS별 감지·URL·프리뷰 경계는 [포트 프리뷰 계약](../../development/port-preview.md#명령어-버튼의-포트-감지)을 따른다.

- `Ctrl/Cmd+N/T`와 `Alt+N`은 일반 셸 탭 줄·본문의 포커스 등록으로 해당 그룹의 `+`와 같은 새 터미널 흐름을 사용한다. 공용 `TmuxTerminalPanel`은 같은 이름 입력을 연다. 키를 PTY·새 파일 생성으로 보내지 않으며 반복·IME·모달은 생성하지 않는다. 브라우저 예약키 조건·탭 닫기·순환은 [공통 단축키 계약](../../development/ui-contracts.md#포커스-기반-탭-단축키)을 따른다.

- `Ctrl/Cmd+Shift+T`는 현재 루트의 터미널 패널에서 최근 닫은 탭부터 다시 연다. 탭 이름·작업 폴더·순서를 보존하고 종료된 셸은 새 세션으로 시작한다. 닫힌 기록이 없으면 아무 동작도 하지 않는다. 패널만 숨기는 동작은 기록하지 않으며 새로고침·루트/계정 전환 시 기록을 비운다. 에이전트·터미널의 닫힌 탭을 합쳐 최대 50개를 메모리에 보관하고 패널 종류별로 최근 항목을 고른다.

- 공통 `AgentTabBar`의 제목·아이콘·탭 여백을 더블클릭(모바일은 더블탭)하면 해당 탭 이름을 편집한다. F2도 같은 입력을 열며 닫기 버튼·이름 입력칸의 더블클릭은 편집을 다시 열지 않는다. 데스크톱 최대화·복귀는 패널 이동 손잡이 더블클릭으로 실행한다.

- 공통 `AgentTabBar`의 우클릭 또는 Shift+F10으로 이름 변경·탭 닫기·데스크톱 탭 최대화/원래 크기로 복귀 메뉴를 연다. 최대화는 대상 탭을 선택한 뒤 해당 패널을 확대하며, 닫기는 기존 세션 종료·확인 흐름을 사용한다. 모바일에는 최대화 항목을 표시하지 않는다. 메뉴 외형과 배치·닫기는 파일탐색기와 공유하는 `ActionMenu`를 사용하며 각 항목은 Iconoir 아이콘과 번역된 텍스트를 표시한다.

- 연결·재연결 상태와 터미널 열기 실패는 본문 상단의 작은 반투명 플로팅 알림으로 표시한다. 명령 버튼 바와 본문 크기를 밀지 않는다.

- xterm은 `allowTransparency`를 켜고 기본 배경을 완전 투명(`#00000000`)으로 지정한다. 본문 컨테이너와 여백에도 배경색을 칠하지 않으며, `terminal.css`가 xterm 뷰포트의 기본 검정 배경을 제거한다. 선택 모드의 텍스트 스냅샷은 가독성과 아래 출력 가림을 위해 기존 테마 배경을 유지한다. 초기 글씨·커서 색상은 앱 토큰을 읽고, 루트 테마 변경 시 기존 터미널의 색상만 갱신한다. 라이트 모드에는 밝은 배경용 ANSI 팔레트를 사용한다. tmux 전역 설정과 내부 프로그램의 명시적인 RGB/256색 지정은 바꾸지 않는다.

- 입력 영역은 에이전트 작성칸과 같이 패널 바탕을 드러내고 상단 구분선·8px 여백·입력칸과 전송 버튼 사이 8px 간격을 사용한다. 입력칸은 테두리 없는 `surface` 배경·작은 모서리·14px 글자와 좌우 8px·상하 6px 패딩을 사용하고, 셸 명령용 고정폭 글꼴을 유지한다. 전송 버튼은 같은 강조색의 32px 위쪽 화살표 버튼이다. 명령 입력에는 접근성 이름을 제공하며 한 줄 시작·최대 160px 자동 확장·초안·이력·Ctrl/Cmd+Enter 전송을 유지한다.

- 모바일 보조키를 텍스트 입력칸 위로 배치하고 Home·End·Ctrl+C를 추가해 11개 키가 한 줄의 가로 폭을 채우도록 했다.
- 보조키 바 높이는 버튼·여백·테두리에 맞춰 늘어나 세로 스크롤과 버튼 잘림을 방지한다.
- 기존 초안·포커스·키보드 잠금·방향키 이력 탐색을 유지한다.
- 세부 계약과 검증은 [공용 패키지](../../development/packages.md)를 따른다.

- 일반 셸 탭 생성·재연결·입력·세션 종료와 터미널 명령 버튼을 제공한다.
