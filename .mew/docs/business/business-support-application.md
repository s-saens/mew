### Key Milestones

While building a sleep-tech app during cohort 1 of Moduui Changupe, I needed an environment where I could develop on the go while continuing my company work.\
Remote agent apps, ssh terminal connections, and other remote access methods were available, but I hit a roadblock whenever I needed to edit files directly, such as secrets and certain documents.\
So I built a web-based, self-hosted IDE server myself. This let me quickly create an MVP and related documents on my phone in my spare time while continuing my company work.

### The Problem We Want to Solve

"Develop software properly and easily, even on mobile"\
Remote agent apps, ssh terminal connections, and similar tools now let people develop the products they want through AI agents simply by opening their smartphones, anytime and anywhere. These mobile development capabilities have strong demand and many users. Yet many people still use desktop IDEs for development. This is because developing software "properly" sometimes requires editing files directly, including document content, secret values, and short pieces of code, or using debugging features, which existing services make difficult on mobile.

### Our Team's Solution to the Defined Problem

Mew provides a rich set of development features quickly, without any restrictions even on mobile. From anywhere and on any device, users can access the development environment on their home server and use an integrated set of features needed to work on a project, including document editing, code changes, agent chat, Git management, terminal commands, task management, remote desktop, and debugging.\
Because I developed it while working on my own projects, I continuously improved it from a user's perspective and optimized its UX and performance. This provides an experience distinct from other existing IDEs and helps users develop products easily.

### Reasons for Applying and Expectations

We plan to adopt an open-core business model, release the code as open source, and monetize it in the following ways.

- Provide a proxy for secure external access to mew running on a home server
- Run mew on cloud servers
- Enterprise support

For the cloud offering in particular, we primarily hope for practical support such as infrastructure assistance, investment to build our own infrastructure, direct collaboration with Naver Cloud, or introductions to companies. We also hope for support such as marketing advice and AI subscriptions for company operations and product development.
