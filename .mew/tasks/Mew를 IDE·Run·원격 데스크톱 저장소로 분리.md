## 목표와 현재 상태

비공개 `mew/` 통합 저장소 아래에서 다음 세 저장소를 독립 Git 서브모듈로 관리한다. 사용자에게 표시하는 Mew 이름과 `mew` 명령은 유지한다.

| 저장소 | 분리 범위 |
| --- | --- |
| `mew-ide/` | IDE를 공개 저장소로 유지한다. |
| `mew-run/` | Run을 비공개 저장소로 유지한다. |
| `mew-remote-desktop/` | 원격 데스크톱을 분리하고 선택 설치 기능으로 제공한다. |

**계획 수립은 끝났으며, 실제 저장소 이전은 아직 시작하지 않았다.** 작업 순서·선행 조건·검증·복구 절차는 [이전 계획](../docs/work/mew-repository-split-plan.md)에서 관리한다. [ADR 0132](../docs/decisions/0132-mew-repository-boundaries.md)에는 합의한 방향과 공개 범위에 관한 미결정 사항이 기록되어 있다.

## 구현 체크리스트

- [ ] Git 이력, 미커밋 변경, 워크트리, 사용 중인 경로의 의존 관계, 영속 데이터와 복구 요건을 파악한다.
- [ ] 공개 공통 패키지와 버전이 명시된 연동 규약을 정의하고, 다른 저장소의 내부 소스 경로를 직접 참조하는 의존성을 제거한다.
- [ ] Mew의 권한 검사와 공통 Mewlink 네트워킹을 유지하면서 원격 데스크톱 엔진과 설치 도구를 분리한다.
- [ ] 독립 하위 저장소와 비공개 통합 저장소를 준비하고, 서브모듈이 참조할 커밋을 고정한다.
- [ ] 원격 데스크톱을 명시적인 선택 설치 항목으로 만들고, 기능을 사용하지 않을 때는 데스크톱 헬퍼를 실행하지 않는다.
- [ ] 새로 체크아웃한 환경과 호환성을 검증한 뒤, 실제 경로 전환 시점을 사용자와 조율한다.
- [ ] 관련 규약·가이드·운영·릴리스 문서를 갱신하고, 실제 검증 결과와 남은 제약을 기록한다.

## 완료 기준

- [ ] 공개 IDE 저장소만 체크아웃한 상태에서 다른 하위 저장소나 비공개 자격 증명 없이 설치·빌드·테스트·실행할 수 있다.
- [ ] Run은 선언된 의존성과 빌드 산출물만으로 빌드되며, 소스와 Git 이력이 공개 IDE 배포물에 포함되지 않는다.
- [ ] 선택 설치한 원격 데스크톱에서 연결·입력·권한 철회·정리 동작이 유지되며, 헬퍼가 없거나 호환되지 않을 때의 복구 경로가 검증되어 있다.
- [ ] 비공개 통합 저장소에서 검증된 하위 저장소 커밋 조합을 재현할 수 있으며, 이전 상태로 되돌릴 때 데이터와 다른 작업의 변경을 보존한다.

체크박스는 **실제 저장소 이전 작업**의 진행 상태를 나타낸다. 이 계획 문서의 작성 완료 여부를 뜻하지 않는다. 구현 일정과 담당자는 아직 정하지 않았다.

서버 시작·중지·재시작, 런처 실행, 배포와 드라이버 설치는 [실행 규칙](../docs/development/getting-started.md)에 따라 사용자가 수행한다.
