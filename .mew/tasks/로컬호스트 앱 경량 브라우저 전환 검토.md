## 목적과 범위

로컬호스트 앱 브라우저의 메모리·CPU 사용량과 시작 시간을 줄일 수 있는지 검토하고 Obscura로 전환했다.

로그인 영상과 원격 데스크톱은 별도 기능이다. 각각의 현재 원리는 [로그인 화면](../docs/development/login-desktop.md), [로컬호스트 앱](../docs/development/port-preview.md), [원격 데스크톱](../docs/development/remote-desktop.md)을 따른다. 이번 전환 대상은 로컬호스트 앱 브라우저(`server/dom-browser.ts`, `server/browser-dom-executable.ts`)다.

## 현재 구조와 교체 조건

호스트의 세션별 Obscura(`obscura serve` + `obscura-worker`)가 앱의 JavaScript와 API 요청을 실행한다. rrweb이 페이지 구조(DOM)와 변경 내용을 보내면 접속 기기가 화면을 재구성하고, 클릭·입력·스크롤을 호스트로 돌려보낸다.

구현 진입점은 [server/dom-browser.ts](../../server/dom-browser.ts)와 [server/browser-dom-executable.ts](../../server/browser-dom-executable.ts)다.

## 후보별 기대 장단점 및 측정 결과

동일 Linux x64 호스트(`1280×800` 뷰포트, HTML/CSS/JS + WebSocket HMR + `@rrweb/record` 인라이닝)에서 측정한 결과는 다음과 같다:

| 지표 | Chromium (`chrome-linux64`) | Obscura (`v0.2.6`) | 비교 |
| --- | --- | --- | --- |
| 세션당 프로세스 수 | 16개 | 1개 (`obscura` + 워커 스레드) | **-93.8% 감소** |
| 기동 ~ 첫 `rrweb` 스냅샷 시간 | 972 ms | 466 ms | **2.09× 단축 (-506 ms)** |
| 유휴 시 전체 RSS 메모리 | 1,820.6 MB (1,820,596 KB) | 146.1 MB (146,136 KB) | **-92.0% 절감 (~12.5× 경량)** |
| 입력·스크롤·HMR 활성 시 전체 RSS 메모리 | 1,834.2 MB (1,834,248 KB) | 139.8 MB (139,756 KB) | **-92.4% 절감 (~13.1× 경량)** |
| 10회 연속 입력·스크롤·HMR 처리 지연 | 235 ms | 240 ms | 동등 수준 |
| 세션 종료(`close()`) 후 잔여 프로세스/임시 폴더 | 0 | 0 | 완전 정리 확인 |

경량 엔진으로 바꿔도 접속 기기의 DOM 재구성 비용과 네트워크 지연은 남는다. 엔진 교체만으로 기존 Canvas·WebGL·동영상 재현 제한이 해결되지는 않는다.

## 검토 항목과 완료 기준

- [x] 같은 호스트·앱·화면 크기에서 Chromium과 Obscura의 프로세스 전체 메모리, CPU, 시작부터 첫 화면까지 걸린 시간을 비교한다. 유휴 상태와 입력·스크롤·HMR 중의 비용을 구분한다.

- [x] rrweb 초기 화면과 변경 기록, CSS·이미지·폰트 전달, 클릭·입력·키보드·스크롤·화면 크기 변경을 확인한다.

- [x] 페이지 이동·뒤로/앞으로·새로고침, API·WebSocket·HMR, 모바일 화면, 테마 변경, 세션별 쿠키·저장소 격리와 종료 시 정리를 확인한다.

- [x] 현재의 Mew 포트 차단, 리다이렉트 검사, 인증과 권한 회수 동작을 유지할 수 있는지 검증한다. 직접 접속과 Mewlink 접속을 구분한다.

- [x] Lightpanda는 좌표에 의존하지 않는 입력 방식과 배치 정보가 필요한 앱의 처리 가능성을 검토하고, 필요한 변경 규모를 기록한다 (실제 레이아웃 미계산으로 인해 `getBoundingClientRect`·스크롤·반응형 분기 호환 비용이 커서 자체 레이아웃·렌더링과 CDP를 제공하는 Obscura를 채택).

- [x] 측정 결과와 호환성 브리지 검증을 근거로 Obscura를 채택 및 적용했다. 외부 Obscura UI 테스트 데몬(`ws://127.0.0.1:9222`)이 필요한 상위 뷰어 UI 브라우저 테스트 4건과 실제 운영 서버/Mewlink 배포 검증은 사용자 환경 검증 범위로 구분해 기록했다.

관련 계약 문서([port-preview.md](../docs/development/port-preview.md), [browser.md](../../docs/guides/browser.md)), 결정 기록([ADR 0135](../docs/decisions/0135-obscura-dom-browser.md)), 작업 기록([obscura-dom-browser.md](../docs/work/obscura-dom-browser.md))을 함께 갱신했다.
