# 프로젝트 조작

프로젝트 목록은 `mew_open_panel`의 `panel: "projects"`로 연다. 데스크톱에서는 `Alt+P`로 프로젝트 사이드바를 열고 모바일에서는 헤더의 현재 프로젝트를 눌러 목록을 연다.

`mew_create_project`의 `parent`는 이미 존재하는 상위 폴더의 절대 경로이고 `name`은 새 폴더 이름이다. 기존 폴더를 덮어쓰지 않으며, 생성 결과의 `path`는 아직 화면에서 열린 프로젝트라는 뜻이 아니다.

`mew_open_project`에 기존 폴더의 절대 경로를 전달한다. 브라우저가 프로젝트 전환을 마쳐야 성공을 반환한다. 프로젝트 생성·열기는 owner와 프로젝트 관리 권한이 있는 manager가 사용할 수 있다. 현재 권한은 `mew_get_context`의 `canManageProjects`로 확인한다.

실패한 요청을 성공했다고 설명하거나 같은 이름의 폴더를 지워서 다시 만들지 않는다. 경로가 불분명하면 사용자가 열려는 폴더를 확인한다.
