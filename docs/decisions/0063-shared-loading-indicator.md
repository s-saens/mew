상태: 채택

## 배경

프로젝트·편집기는 테두리 링, 댓글 전송은 회전하는 새로고침 아이콘, 첨부 업로드와 Mewlink는 별도 CSS 스피너를 사용했다. 회전 속도·트랙·강조 방향도 달라 같은 대기 상태가 서로 다르게 보였다.

## 결정

`@mew/ui`의 `LoadingIndicator`와 `loading-indicator.css`로 원형 대기 표시를 통일한다. React를 사용하지 않는 비공개 Mewlink도 같은 CSS를 직접 가져온다. 크기와 상속 색은 사용 위치에서 정하고 링 형태·회전 속도·모션 감소 처리는 공용 CSS가 소유한다. 구체적인 값과 사용 범위는 [공용 UI 계약](../development/ui-contracts.md#공용-로딩-인디케이터)을 따른다.

에이전트의 빈 말풍선 skeleton은 콘텐츠 형태를 미리 보여주는 용도로 유지한다. 연결 상태와 알림 유무를 나타내는 표시는 해당 의미를 보존한다.

## 혜성 궤도 디자인 보완

단순한 링의 표현을 강화하되 기존 공통화와 컴포넌트 API는 유지한다. 단일 span과 두 가상 요소에 정적인 그라데이션·마스크를 적용해 빛의 꼬리와 반대 방향의 궤도를 그린다. 애니메이션은 transform으로 한정하고 모션 감소·강제 색상·숨김 상태를 지원한다. 실제 기기 성능을 보장하는 수치로 해석하지 않도록 검증은 격리 Chromium의 합성·페인트 측정과 운영 확인을 구분한다.

## 근거와 영향

공용 스타일 하나를 수정하면 Mew와 Mewlink의 원형 로딩이 함께 바뀐다. Mewlink에 React 의존성을 추가하지 않으며 기존 상태 안내와 모션 감소 설정을 유지한다. 비공개 중앙 소스는 Git 제외를 유지한다. 운영 반영은 사용자가 수행하는 로컬 앱 빌드와 중앙 프론트 배포가 각각 필요하다.
