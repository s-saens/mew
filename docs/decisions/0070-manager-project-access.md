## 배경

manager는 에이전트·터미널과 서버 파일 탐색기로 서버 OS 파일에 접근할 수 있지만 프로젝트 선택기를 열 수 없어 정상 작업 공간 전환이 막혔다.

## 결정

owner·manager에게 헤더 프로젝트 목록·추가·전환·아이콘 변경과 단축키, 서버 파일 탐색기의 프로젝트 열기, 하위 프로젝트·worktree 전환을 허용한다. 선택 창의 폴더 탐색·클라우드 목록·폴더 생성·Git clone/초기화와 뮤펫의 프로젝트 열기·생성도 같은 역할을 따른다. 목록·활성 루트·화면 복원은 계정별 저장을 유지한다.

member·guest는 현재 프로젝트 표시만 사용한다. 계정 관리·Mewlink 관리·Documents 설정/가져오기/내보내기와 기존 `/project` 생성·개명·삭제 API는 owner 전용으로 유지한다. 파일·기능 권한과 서버 데이터 경로 차단은 기존 계약을 따른다.

## 근거와 영향

manager의 프로젝트 UI와 서버 API가 기존 서버 작업 권한에 맞게 동작한다. 드롭다운만 열고 API가 거부하는 불일치를 없애며 다른 계정의 활성 루트나 실행 중 세션의 cwd는 변경하지 않는다.

현재 계약은 [프로젝트 기능](../features/프로젝트·파일·검색/프로젝트%20열기·탭·그룹.md)과 [접근 제어](../development/access-control.md)를 따른다.
