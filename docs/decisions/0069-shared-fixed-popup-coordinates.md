## 상태

채택.

## 배경

모달의 `backdrop-filter`는 내부 `position: fixed` 요소의 좌표 기준점을 바꾼다. 화면 좌표를 그대로 적용한 즐겨찾기·작업 메뉴·멘션 목록은 모달 위치만큼 밀렸다. 선택 필드·계정 팝업·툴팁에는 개별 보정이 있었지만 테두리·스크롤·부모 잘림 처리가 달랐다.

원점만 보정해도 `overflow: hidden`인 모달 밖의 메뉴는 잘린다. 모든 메뉴를 body로 옮기면 기존 모달 포커스 제한과 전체화면 경계를 벗어난다.

## 결정

`@mew/ui`의 `getFixedPopupLayout`이 fixed 기준 요소, 화면에서 실제 보이는 영역, CSS 좌표 변환을 함께 계산한다. 각 팝업은 기존 portal과 열림 방향·선택·닫기 동작을 유지하면서 이 공통 계산을 사용한다. 기준 요소의 테두리·스크롤·축 방향 확대를 반영하고, 잘리는 영역 안에서 메뉴 크기를 제한해 내부 스크롤로 항목에 접근한다.

원격 화면처럼 회전하는 컨테이너의 선택 필드는 기존 역행렬을 이용한 로컬 배치를 유지한다. 구체적인 적용 대상과 검증은 [팝업 좌표 계약](../development/ui-contracts.md#모달-내부-팝업-좌표)을 따른다.

## 근거와 영향

테마에 따라 블러가 켜져도 같은 공통 계산으로 위치를 맞춘다. 새 드롭다운에 별도 원점 보정을 추가할 필요가 없고 모달 내부 포커스·Esc·뒤로가기 처리를 유지할 수 있다. 메뉴를 표시할 공간이 작으면 높이를 줄이며, 검증에서는 좌표뿐 아니라 표시된 항목의 실제 클릭 가능 여부도 확인한다.
