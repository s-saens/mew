## 상태

채택. [계정별 설정 결정](../history/decisions/0202-mew-account-agent-settings.md)의 저장 범위를 유지하고, [기본 지침 설정 결정](../history/decisions/0171-mew-agent-guidance-settings.md)의 창에 프로젝트 편집을 추가한다.

## 배경

계정 공통 지침은 에이전트 패널에서, 프로젝트 지침은 Documents 설정에서 편집해 적용 범위를 알아보기 어려웠다. 빌드·서버 재시작처럼 특정 저장소에 필요한 규칙을 전역 기본값으로 오해하면 다른 프로젝트의 작업까지 제한할 수 있다. 같은 창에서 범위를 선택하고 저장 대상을 확인할 수 있어야 한다.

## 결정

에이전트 기본 지침 창에 **뮤 전역 지침**과 **현재 프로젝트**를 둔다. 뮤 전역은 로그인한 계정의 모든 프로젝트에 적용하는 지침이며 다른 계정에는 적용하지 않는다. 기존 프리셋·Git 설정에 추가 지침 편집을 제공하고, 현재 프로젝트에서는 자동 안내 사용 여부와 프로젝트 추가 지침을 편집한다.

두 범위 모두 기존 기준본을 사용한다. 계정 전역은 계정별 `agent-guidance.md`의 전용 설정 구간에, 프로젝트는 `<프로젝트>/.mew/agent-context.json`에 저장한다. 다른 설정·자유 지침을 옮기거나 덮어쓰지 않는다. 기존 전역 `serverFiles` 권한과 프로젝트 owner 경계, revision 충돌 검사를 유지한다. 저장 실패 시 초안을 보존하고 프로젝트를 바꾼 뒤 이전 프로젝트의 초안을 저장하지 않는다.

프로젝트 추가 지침은 해당 프로젝트에서 충돌하는 Mew 전역 선호보다 우선한다고 전달한다. 명시적인 사용자 요청과 프로젝트의 기존 지침은 유지한다. 저장한 내용은 다음 실제 ACP 요청부터 읽으며, 프로젝트 자동 안내를 끄면 두 범위 모두 전달하지 않는다.

빌드·실행·재시작 제한은 각 프로젝트가 정한다. Mew 전역 기본 템플릿에 일괄 금지를 넣지 않는다. Mew 소스 저장소의 실행 제한은 이 저장소의 `.mew/agent-context.json`·`AGENTS.md`·개발 문서에 둔다. 기존 사용자 지침을 일괄 검색·삭제하거나 자동으로 다른 범위로 옮기지 않는다.

설정창은 전체 Settings 팝업의 표면·탐색 구성과 공통 크기를 따르며 제목줄·닫기 아이콘을 작게 배치한다. 작은 제목과 간결한 행을 유지하고, 데스크톱은 왼쪽 탐색·모바일은 가로 탐색으로 범위를 선택한다. 구체적인 사용법은 [프로젝트 설정 안내](../guides/project-setup.md#공통-안내-파일-편집), 저장·API는 [세션 계약](../development/agent-sessions.md#프로젝트-컨텍스트-전달), UI·검증은 [소유 기능 문서](../features/프로젝트·파일·검색/프로젝트%20문서%20안내·초기화.md)가 소유한다.

## 근거와 영향

한 창에서 범위와 저장 대상을 확인할 수 있고 기존 Documents 설정과 중복 저장소를 만들지 않는다. 계정별 설정을 인스턴스 전체 공용으로 넓히지 않으며, 프로젝트 설정을 편집할 권한도 확대하지 않는다. 지침 우선순위는 에이전트에게 전달하는 안내이며 런타임의 상위 지침이나 서버 권한을 변경하지 않는다. 저장만으로 앱 빌드·실행·재시작이 일어나지 않는다.
