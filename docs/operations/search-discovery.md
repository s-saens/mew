# 공개 소개와 작업 공간의 검색 정책

Mew 호스트는 문서·코드·에이전트를 다루는 작업 공간이다. 검색 유입을 받을 공개 제품 소개와 설치된 작업 공간을 구분한다. 제품의 현재 공개 원출처는 [공식 저장소 README](https://github.com/s-saens/mew#readme)이며, Mewlink의 역할은 [프로젝트 소개](../../README.md#open-it-from-another-device)와 [도메인 결정](../decisions/0005-mewlink-domain-and-private-dashboard.md)을 따른다.

## 작업 공간의 현재 정책

[색인 경계 결정](../decisions/0057-workspace-search-indexing.md)에 따라 호스트의 직접 HTTP·Vite 개발 응답은 `X-Robots-Tag: noindex, nofollow`를 반환한다. HTML 진입점에도 같은 robots 메타를 넣고, 제품을 설명하는 제목과 description을 제공한다. P2P는 같은 호스트 HTTP 처리를 사용하며 전달 헤더 목록에 `X-Robots-Tag`를 보존한다. 설치된 HTML에 robots 메타가 포함되려면 사용자가 새 UI를 빌드·적용해야 한다.

`GET /robots.txt`와 `HEAD /robots.txt`는 `text/plain`·200·`Cache-Control: no-cache`로 응답한다. 내용은 다음과 같다.

```text
User-agent: *
Allow: /
```

크롤러가 페이지의 `noindex`를 읽을 수 있도록 수집 요청 자체는 허용한다. `Disallow: /`와 `noindex`를 함께 쓰면 크롤러가 `noindex`를 보지 못할 수 있다. 근거는 [Google의 색인 제외 안내](https://developers.google.com/search/docs/crawling-indexing/block-indexing)다. robots와 noindex는 크롤러가 따르는 검색 정책이며, 접근 권한은 기존 [인증·파일 권한](security.md)이 집행한다.

게스트에게 허용한 문서·파일과 알 수 없는 SPA 경로도 호스트 응답 정책을 따른다. 라우팅 호환을 위해 SPA의 200 fallback은 유지한다. 브라우저 데모의 기존 `noindex`도 유지한다. 별도 중앙 서비스의 공개 소개·대시보드·기기 접속 페이지와 `app.mew.run`의 응답은 이 호스트 미들웨어의 적용 대상이 아니므로 별도로 확인한다.

## 공개 제품 사이트의 설정 조건

대표 공개 주소와 그 사이트의 소스·배포 소유권을 확정한 뒤 다음 순서로 설정한다. 호스트마다 다른 주소로 설치되는 작업 공간에는 임의 canonical·사이트맵·`llms.txt`를 만들지 않는다.

1. 로그인 없이 받은 HTML에 제품의 실제 기능·설치 방법·출처 링크를 제공한다. 비공개 작업 문서·대화·기기 목록은 포함하지 않는다.
2. 실제 공개 페이지에 고유 title·description·canonical·공유 메타를 넣는다. 구조화 데이터는 화면에 보이는 사실과 일치시킨다.
3. 공개 정본 URL만 사이트맵에 담고 robots에서 연결한다. 없는 공개 페이지가 실제 404인지 확인한다.
4. 검색·실시간 조회 크롤러와 학습 크롤러의 허용 정책을 운영자가 정한다. `llms.txt`에는 검증된 제품·설치·지원 문서만 안내한다. 이 파일의 존재만으로 AI 인용을 보장하지 않는다.
5. 운영자가 Google Search Console·Bing Webmaster Tools·네이버 서치어드바이저에서 소유권을 확인하고 사이트맵을 제출한다. 계정이나 검증 토큰 없이 등록 완료로 표시하지 않는다.

공개 블로그는 반복해서 답할 실제 질문·원출처·검수 담당자·발행 리듬을 정한 뒤 만든다. 검색어·문의 데이터가 없는 상태에서 질문별 페이지나 발행 일정을 대량 생성하지 않는다.

## 2026-10-23 초기 진단

아래는 변경 전 소스와 접근 가능한 공개 응답의 관측이다. 공개 검색 콘솔이나 AI 답변 서비스의 성과 데이터에는 접근하지 않았다.

| 레인 | 상태 | 근거 |
| --- | --- | --- |
| SEO | ⚠️ | 호스트 HTML은 빈 React 진입점이며 제목만 있었다. 설명·색인 정책·사이트맵이 없었다. 작업 공간의 공개 색인은 목표로 삼지 않는다. |
| AEO: 답변 추출 | ⚠️ | 호스트에 공개 제품 답변 HTML이나 구조화 데이터가 없다. FAQ를 실제 본문 없이 추가하지 않는다. |
| GEO: AI 검색 인용 | ⚠️ | 대표 공개 사이트의 크롤러 정책·`llms.txt`를 검증하지 못했다. |
| LLMO: 제품 인지 | ✅ | 공식 GitHub README에 제품 정의·기능·설치 경로가 있다. 모델의 실제 인지·인용 여부는 미측정이다. |
| NEO: 네이버 노출 | ⚠️ | 한국어 설치 가이드가 있으나 공개 대표 주소의 수집·소유 확인·인용 상태는 미측정이다. |
| 콘텐츠 운영 | ⚠️ | 저장소에 제품 소개와 4개 언어 설치 가이드가 있다. 공개 블로그 인벤토리·질문 매핑·발행 주기·노출 수치는 확인하지 못했다. |

이 환경에서 `https://mew.run/`, `/robots.txt`, `/sitemap.xml`, `/llms.txt`, `/blog`, `/feed.xml`, 확인용 미존재 경로를 일반 비인증 요청으로 조회했을 때 모두 403과 `text/plain`을 받았다. 정책인지 관측 환경의 제한인지 원인을 확정하지 않는다. 이 결과로 사이트맵의 부재나 운영 사이트의 404 처리를 판정하지 않는다.

## 운영 반영과 재측정

에이전트는 소스와 격리 검사를 수행하며 앱 빌드·서버 재시작·중앙 배포는 운영자가 수행한다. 로컬 검사 통과는 운영 적용이나 검색 성과를 뜻하지 않는다.

2026-10-23 격리 HTTP fixture를 `curl`로 확인해 robots의 200·텍스트 본문과 HTML의 `X-Robots-Tag`·제목·설명·robots 메타를 검증했다. `server/search-indexing.test.ts`·`server/remote-ui.test.ts`·`server/vite-config.test.ts`의 5개 검사, 타입 검사·변경 TypeScript lint·문서 description/링크 검사도 통과했다. P2P 검사는 실제 dispatcher가 설치 HTML 메타와 헤더를 전달하는 범위이며, 중앙 공개 서비스의 배포·검색 수집은 검증하지 않았다.

반영 직후 운영자는 공개 진입점에서 아래를 확인한다. `HOST`에는 본인이 관리하는 호스트 주소를 쓴다.

```bash
curl -sS -D - "$HOST/robots.txt"
curl -sS -I "$HOST/"
curl -sS "$HOST/" | rg '<title|name="(description|robots)"'
```

robots는 위의 텍스트 응답이어야 하고 HTML·파일 응답의 `X-Robots-Tag`에는 `noindex`가 있어야 한다. P2P는 동일 설치본의 HTML 메타와 전달 헤더를 별도로 확인한다. 중앙 공개 소개는 호스트의 `noindex`를 상속하지 않는지 그 소유 배포에서 확인한다.

2026-10-23 반영을 가정한 첫 재측정 제안일은 **2026-11-06**이다. 자동 예약은 만들지 않았다. 실제 반영일이 다르면 그날부터 14일 뒤로 조정한다.

| 측정 대상 | 반영 직후 기준선 | 14일 뒤 확인 |
| --- | --- | --- |
| 작업 공간 | HTML·헤더의 `noindex`, 게스트/로그인 권한 | Search Console 접근 권한이 있으면 제외 상태 확인. 개인 경로를 공개 검색창에 입력하지 않는다. |
| 공개 사이트 SEO·네이버 | 최근 28일 노출·클릭·색인 상태를 GSC·Bing·서치어드바이저에서 기록 | 집계가 끝나지 않은 최근 2~3일을 빼고 같은 지표·페이지를 비교한다. |
| 공개 사이트 AI 인용 | 실제 제품·설치 질문 5~10개와 ChatGPT 검색·Perplexity·네이버의 출처 URL을 기록 | 같은 질문·서비스에서 인용 여부와 주소를 다시 기록한다. |
| 공개 콘텐츠 | URL·대상 질문·원출처·실제 수정일·노출/클릭을 글별로 기록 | 노출·인용된 글 비율과 사실 갱신 필요 여부를 확인한다. |

현재 노출·클릭·인용 수치는 **미측정**이다. 0으로 기록하거나 개선을 주장하지 않는다.
