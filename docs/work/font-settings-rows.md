불필요한 글꼴 안내 문구와 라벨 아래로 쌓인 선택칸을 정리했다. 현재 사용법은 [화면 설정](../configuration/appearance.md#화면-설정), 구현 계약은 [화면 설정 기능](../features/화면·계정·운영/화면·언어·글꼴·단축키%20설정.md)이 소유한다.

각 행을 라벨·선택칸·초기화 버튼으로 구성하고 공통 그리드로 선택칸의 시작 위치를 맞췄다. 라벨은 해당 입력칸과 연결했다. 추천 선택·글꼴 이름 입력·개별 초기화·브라우저 저장은 유지한다.

`node --test server/theme-color-ui.test.ts src/i18n.test.ts src/utils/fontPreferences.test.ts`의 9개 검사를 통과했다. 격리 Chromium에서 320/390/1100px·라이트/다크와 네 언어의 한 줄 배치·선택칸 정렬·화면 경계·안내 문구 부재·라벨 포커스·기존 글꼴 입력/초기화를 검사했고 PC·모바일 캡처도 확인했다. 열린 팝업이 다른 컨트롤을 덮는 경우 테스트에서 먼저 Esc로 닫도록 조정했다.

`npx tsc -b`와 변경 코드·테스트의 린트는 오류 없이 완료했다. 린트에는 기존 Fast Refresh 경고가 남았고 레이아웃 검사에는 발견 항목이 없었다. 전체 문서 검사는 작업 범위 밖의 누락 링크로 실패했으며 변경 문서의 description과 직접 링크는 별도로 확인했다.

앱 빌드·배포·서버 실행·재시작은 수행하지 않았다. 실제 인스턴스 적용은 사용자가 수행한다.
