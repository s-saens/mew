프로젝트의 기능 명세·공유 구현 계약·결정·작업 근거는 [프로젝트 문서](../.mew/docs/AGENT.md), 진행할 일은 [태스크](../.mew/tasks/_tasks.md)에 둔다. 문서 작성과 분류는 [작성 규칙](../.mew/docs/README.md)을 따른다.

가이드 이미지는 `docs/assets/`의 영구 파일을 저장소 상대 경로로 연결한다. 앱의 임시 업로드 API 주소는 공개 문서에 사용하지 않는다.
